### EPIC-001 · approved · source: planning:EPIC-001

Create and List Notes (Sprint 1): any visitor can create a short note and see all notes in a single shared, newest-first list with a friendly empty state.

No sign-in and no per-user or per-browser separation; every visitor sees and edits the same global list.

**Related:** US-001, US-002, US-003

### EPIC-002 · approved · source: planning:EPIC-002

Delete Notes (Sprint 2): any visitor can permanently delete a note from the shared list after confirming the action.

### EPIC-003 · approved · source: planning:EPIC-003

Export Notes as Markdown (Sprint 2): any visitor can export notes as a single, date-named Markdown file downloaded to their device, capped by a configurable setting (default 100), keeping the most recent notes.
